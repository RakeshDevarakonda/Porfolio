## 🌟 Key Features & 3D Interactions

- **3D Microservice System Core (`Three.js`)**: Interactive 3D wireframe core with raycasting mouse-hover tooltips for active microservice nodes (*WebSockets*, *PostgreSQL*, *AWS SQS*, *REST APIs*).
- **Background 3D World Canvas**: Real-time scroll-driven Three.js background scene with 28 server monolith towers and horizon grid animation.
- **Interactive 3D Fibonacci Skill Matrix**: Hexagonal crystal nodes with 3D canvas text sprites, raycasting mouse hover HUD tooltips, and category isolation filters (*All*, *Backend*, *Languages*, *Database*, *Cloud*, *Real-Time*).
- **Executable ZSH Terminal Emulator**: Interactive CLI emulator with executable quick commands (`whoami`, `focus.txt`, `location.json`, `stack.sh`, `clear`).
- **3-Layer Cyber Reticle Cursor**: Interactive custom reticle cursor with tactical halo, tracking dot, crosshairs, and dynamic action labels (*[COPY EMAIL]*, *[VIEW REPO]*).
- **3D Preloader Boot Screen**: Full-screen AAA system boot loader with live percentage progress counter and diagnostic status messages.
- **Glassmorphic Cyberpunk Theme**: Permanent dark aesthetic with glowing cyan, blue, and mint lighting effects.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: `v18.x` or higher
- **npm**: `v9.x` or higher

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/RakeshDevarakonda/Porfolio.git

# 2. Navigate into the directory
cd Porfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production

```bash
# Run strict TypeScript verification and Vite bundle build
npm run build
```

Production output will be generated in the `/dist` directory.
